# MS Motors Studio — thème WordPress

Thème sur mesure du garage MS MOTORS STUDIO (Mainvilliers), dans le dossier `ms-motor-studio/`.

## Charte (v2.1)

- Noir chaud, ivoire et or mat en touche discrète ; filets d'un pixel, aucun cadre ni dégradé.
- Titres en **Instrument Serif** (italique pour les mots mis en valeur), textes en **Manrope** légère.
- Bouton principal ivoire, bouton secondaire au contour fin.

## Installation

Compresser `ms-motor-studio/` en zip, puis Apparence → Thèmes → Ajouter → Téléverser. Les coordonnées se règlent dans Apparence → Personnaliser.
